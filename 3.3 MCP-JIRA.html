Jira Integration for Claude Code via MCP

Complete reference for configuring, authenticating, and running Jira tools inside Claude Code.

Option 1: Official Atlassian Remote MCP Server (OAuth 2.1)

Recommended for interactive desktop use. Uses Atlassian's hosted MCP endpoint with browser authentication.

  1. Add the Server: 
    claude mcp add --transport http atlassian https://mcp.atlassian.com/v2/mcp
  2. Authenticate via Browser:

    Launch Claude Code and trigger the MCP manager:

    claude

    Type /mcp inside the interactive session, follow the OAuth link generated in the terminal, and approve your Jira workspace in the browser.

Option 2: Local Stdio Server (API Token / Headless)

Recommended for CI/CD environments or setups that prohibit OAuth callbacks.

  1. Generate an Atlassian API Token:

    Visit Atlassian Account Security and create a token.

  2. Add via claude mcp add: 
    claude mcp add \
  --transport stdio \
  --scope user \
  --env JIRA_URL="https://your-domain.atlassian.net" \
  --env JIRA_EMAIL="your.email@company.com" \
  --env JIRA_API_TOKEN="YOUR_ATLASSIAN_API_TOKEN" \
  jira -- npx -y @rui.branco/jira-mcp
Tip: You can alternatively define this inside your project root's .mcp.json file to avoid raw credentials in shell history: 
{
  "mcpServers": {
    "jira": {
      "command": "npx",
      "args": ["-y", "@rui.branco/jira-mcp"],
      "env": {
        "JIRA_URL": "https://your-domain.atlassian.net",
        "JIRA_EMAIL": "your.email@company.com",
        "JIRA_API_TOKEN": "YOUR_ATLASSIAN_API_TOKEN"
      }
    }
  }
}

Verification and Testing

  • Check Connection Status: 
    claude mcp list
  • Sample Prompts to Test: 
    claude
> "Show me all open bugs assigned to me in the current sprint."
> "Find Jira issue PROJ-101 and display its acceptance criteria."
